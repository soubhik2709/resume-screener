# ATS Resume Screener - Frontend UI

This is the Next.js 16 client application built with Tailwind CSS v4 and TypeScript.

## Local Development Setup

1. Move into this directory: `cd frontend`
2. Install dependencies: `npm install`
3. Start the development server: `npm run dev`

## Core Core Interfacing Features
- Multipart/form-data multi-file upload pipeline.
- Type-safe ATS scoring dashboard tables.
